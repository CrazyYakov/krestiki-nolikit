# Игра | Крестики - нолики

Это консольная игра "крестики нолики" предназначенная для демонстрации моих навыков. 

Проект будет написан с нуля. Дабы оценить возможности работы с языком программирования.

# Правило игры

Два игрока по очереди размещают свои фигуры (крестик или нолик по выбору) на игровом поле. Игровое поле разделено на несколько квадратов.
Побеждает тот кто первым выстроил свои 3 фигуры в ряд. 

### Сценарий игры

1. Два игрока вводят свои имена для счетчика побед.
2. По очереди пишут координаты своих фигур.
